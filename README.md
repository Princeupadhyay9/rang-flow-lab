# RANG Flow Lab — 3D Water Sort

A colourful, relaxing water-sort puzzle game built with React, TypeScript and Vite.

## Features
- Tap-to-pour water sorting puzzle
- Progressive levels with up to 8 colours
- Undo, hint, restart and pause controls
- Move count and completed-colour progress
- Best-level and current-level saved in browser local storage
- Responsive layout for mobile and desktop

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
The production site is generated in the `dist` folder.
